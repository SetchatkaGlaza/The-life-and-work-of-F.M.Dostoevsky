# Ф. М. Достоевский — жизнь, человек, текст

Современный адаптивный образовательный сайт о Фёдоре Михайловиче Достоевском (1821–1881).

Проект задуман не как «страница с биографией», а как цифровой маршрут: пользователь может быстро войти в тему через главную, затем отдельно изучить жизнь писателя, полную хронологию, произведения, идеи, Петербург, семью и окружение, а в конце проверить себя.

## Что внутри

- **Главная** — визуальный вход в проект, ключевые факты, интерактивная хронология, произведения, идеи, литературный Петербург и мини-викторина.
- **Биография** — последовательный рассказ о детстве, образовании, ранней литературной славе, кружке Петрашевского, аресте, инсценировке казни, каторге, военной службе, возвращении в литературу, редакторской работе, путешествиях, семейной жизни и позднем периоде.
- **Хронология** — расширенная временная шкала от семейной истории до смерти и похорон.
- **Произведения** — каталог основных романов, повестей, рассказов и публицистики с фильтрами и контекстом.
- **Идеи** — свобода, вина, вера и сомнение, сострадание, ответственность, подпольное сознание, тема «другого».
- **Петербург** — реальные адреса и литературные пространства, связанные с жизнью Достоевского и его текстами.
- **Семья и окружение** — родители, братья и сёстры, первая и вторая семья, литературный круг, петрашевцы и важные современники.
- **Галерея** — 20 визуальных материалов: портреты, рукописи, первые издания и иллюстрации из открытых источников.
- **Контекст** — журналы, письма, тетради, историческая среда, влияние и способы чтения.
- **Источники** — музейные, библиотечные и культурно-образовательные материалы, использованные для проверки фактов.

## Важный принцип

Сайт не пытается представить спорные литературоведческие трактовки как бесспорные факты. Биографические даты и события по возможности сверяются с музейными и библиотечными источниками. Цитаты не выдаются за слова автора без контекста.

## Технологии

Проект намеренно остаётся лёгким статическим сайтом:

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Manrope + Playfair Display)
- GitHub Actions для базовой проверки
- без обязательного Node.js/npm для запуска

Никаких тяжёлых UI-фреймворков здесь не требуется: сайт работает как обычный статический набор HTML/CSS/JS.

## Как запустить локально

### Вариант 1 — Python

Если установлен Python 3:

```bash
python -m http.server 8080
```

После этого откройте:

```text
http://localhost:8080/
```

### Вариант 2 — Node.js

Если установлен Node.js:

```bash
npx serve .
```

или:

```bash
npx http-server .
```

Откройте адрес, который напечатает сервер.

### Почему нужен HTTP-сервер

Открывать `index.html` двойным кликом можно, но локальный сервер предпочтительнее: он ближе к реальному размещению сайта и корректнее работает с ресурсами, навигацией и браузерными ограничениями.

## Проверка JavaScript

Для проверки синтаксиса:

```bash
node --check app.js
```

Для визуальной проверки рекомендуется пройти все страницы на desktop и mobile и отдельно проверить:

1. основное меню;
2. мобильное меню;
3. переходы между страницами;
4. фильтры произведений;
5. модальные окна;
6. интерактивную хронологию;
7. карту Петербурга;
8. викторину;
9. клавиатурную навигацию;
10. режим `prefers-reduced-motion`.

## GitHub Actions

В репозитории есть workflow `.github/workflows/validate.yml`. Он проверяет наличие основных файлов и синтаксис `app.js` при push/PR.

## Адаптивность

Верстка рассчитана на:

- большие desktop-экраны;
- ноутбуки;
- планшеты;
- смартфоны.

Мобильная версия проектировалась отдельно: сетки перестраиваются, навигация превращается в меню, карточки становятся одноколоночными, интерактивные элементы сохраняют удобную touch-зону.

## Доступность

В проекте предусмотрены:

- семантические HTML-элементы;
- `aria-label` для интерактивных зон;
- skip-link;
- управление модальными окнами с клавиатуры;
- видимые состояния интерактивных элементов;
- поддержка `prefers-reduced-motion`;
- достаточная контрастность основных блоков.

## Статус

Это учебно-образовательный проект, переработанный из старого курсового в современный интерактивный сайт. Контент построен как расширяемая цифровая энциклопедия. Для произведений предусмотрены подробные досье с сюжетом, героями, темами, историей создания и ссылками на полный текст. Визуальный архив использует открытые исторические материалы, прежде всего Wikimedia Commons. Дальше проект можно наращивать отдельными страницами персонажей, интерактивной картой маршрутов, фильмографией и аудиоматериалами.
