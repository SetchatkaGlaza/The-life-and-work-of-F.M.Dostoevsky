# Ф. М. Достоевский — цифровой литературный музей

Полностью переработанный статический сайт о Фёдоре Михайловиче Достоевском (1821–1881). Новая версия построена не как обычный учебный лендинг, а как тёмный цифровой литературный музей: крупная типографика, кинематографичные изображения, рукописи, плавные переходы и отдельные досье для произведений.

## Что изменилось в редизайне

- новая визуальная система: почти чёрный фон, тёплая бумага, глубокий красный акцент;
- крупная редакционная типографика вместо «пластиковых» карточек;
- зернистая текстура, мягкие световые пятна и кинематографичные изображения;
- scroll-progress, reveal-анимации, hover-переходы, интерактивные фильтры;
- мобильное полноэкранное меню;
- каждая ключевая книга вынесена на собственную страницу в `books/`;
- галерея и рукописи используются как часть повествования, а не как декоративный фон;
- сохранена семантическая разметка и поддержка `prefers-reduced-motion`.

## Как запустить локально

### Python

В корне проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

### Node.js

```bash
npx serve .
```

или:

```bash
npx http-server .
```

### Проверка JavaScript

```bash
node --check app.js
```

HTTP-сервер предпочтительнее двойного клика по `index.html`: так сайт работает в условиях, близких к реальному размещению.

## Лицензии

У каждого внешнего изображения необходимо проверять условия конкретного файла. Не следует считать весь Wikimedia Commons единым лицензионным набором: права и требования атрибуции указаны на страницах отдельных материалов.

## Принцип проекта

Дизайн сознательно серьёзный и мрачный, но не «хоррор»: красный используется как акцент, а не как декоративная заливка. Анимации должны усиливать ощущение чтения и исследования, а не превращать литературный материал в аттракцион.
