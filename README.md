# Ф. М. Достоевский — цифровой литературный музей

Современный статический образовательный сайт о Фёдоре Михайловиче Достоевском (1821–1881). Проект переосмыслен как **тёмный цифровой литературный музей**: крупная типографика, архивные изображения, рукописи, отдельные страницы произведений, интерактивная хронология, визуальный архив и контекст эпохи.

## Концепция

Сайт не пытается имитировать «старинный» интерфейс. Основа — современная редакционная эстетика с мрачной атмосферой, характерной для тем Достоевского:

- почти чёрный фон;
- тёплый цвет бумаги;
- глубокий красный как редкий акцент;
- Cormorant Garamond + Manrope;
- архивные фотографии и рукописи;
- крупная типографика;
- плавные reveal-анимации;
- hover-состояния и микровзаимодействия;
- интерактивные фильтры;
- адаптация для мобильных устройств;
- `prefers-reduced-motion`.

Анимации используются как часть навигации и ритма чтения, а не как декоративный шум.

## Что внутри

### Основные разделы

- **Главная** — вход в атмосферу проекта.
- **Жизнь** — биография и ключевые переломы судьбы.
- **Хронология** — события жизни и творчества по годам.
- **Книги** — каталог произведений.
- **Идеи** — свобода, вина, вера, сомнение, сострадание, ответственность и другие темы.
- **Петербург** — город как пространство жизни и литературы.
- **Люди** — семья, друзья, современники и окружение.
- **Архив** — портреты, рукописи, первые издания и визуальные документы.
- **Контекст** — журналы, историческая среда, поездки, письма и рецепция.
- **Источники** — библиография и ссылки на проверяемые материалы.

## Локальный запуск

Проект не требует сборщика и зависимостей.

### Вариант 1 — Python

Откройте терминал в корне проекта:

```bash
python -m http.server 8080
```

После запуска откройте:

```text
http://localhost:8080/
```

### Вариант 2 — Node.js

```bash
npx serve .
```

После запуска откройте адрес, который покажет команда.

### Почему лучше HTTP-сервер

Не рекомендуется просто открывать HTML двойным кликом через `file://`. HTTP-сервер позволяет браузеру работать с проектом так, как он будет работать после публикации, и корректно обрабатывать локальные ресурсы.

## Проверка проекта

Проверить синтаксис JavaScript:

```bash
node --check app.js
```

Запустить полный статический тест:

```bash
node tests/validate.mjs
```

Тест проверяет:

- наличие обязательных страниц;
- наличие `<title>`;
- наличие кодировки;
- локальные `href`;
- локальные `src`;
- изображения и другие локальные ресурсы;
- структуру проекта.

GitHub Actions запускает эти проверки при push в `main`.

## Источники и фактчекинг

Для биографических и литературоведческих сведений используются прежде всего:

- Литературно-мемориальный музей Ф. М. Достоевского;
- Русская виртуальная библиотека;
- Культура.РФ;
- Wikimedia Commons для визуальных материалов.

Особенно важна проверка конкретного материала: Wikimedia Commons не является одной общей лицензией — условия использования необходимо смотреть на странице каждого изображения.

## Визуальные материалы

В проекте используются исторические портреты, фотографии, рукописи и изображения первых изданий. В Wikimedia Commons доступны отдельные коллекции портретов Достоевского и десятки материалов с его рукописями.

При дальнейшей публикации желательно сохранить attribution для каждого внешнего изображения в отдельной странице/таблице визуальных источников.

## Доступность

- семантические HTML-элементы;
- `alt` для содержательных изображений;
- клавиатурная навигация;
- `prefers-reduced-motion`;
- адаптивные мобильные состояния;
- читаемая контрастная типографика.

## Важно

Проект остаётся статическим сайтом: для локального запуска не нужен npm install и не требуется build step.

Главная цель — не сделать очередной «сайт о писателе», а создать ощущение цифрового архива, в котором посетитель последовательно проходит через **человека → эпоху → город → текст → идеи → рукопись**.
