# Ф. М. Достоевский — цифровой литературный музей

Современный статический образовательный сайт о Фёдоре Михайловиче Достоевском (1821–1881): биография, хронология, произведения, идеи, Петербург, окружение, визуальный архив и исследовательский контекст.

## Что внутри

- единая тёмная редакционная дизайн-система;
- архивные портреты, рукописи и первые издания;
- отдельная страница для каждого из 15 ключевых произведений;
- интерактивная хронология, фильтры, модальные карточки и викторина;
- адаптивная вёрстка для desktop, tablet и mobile;
- поддержка `prefers-reduced-motion`;
- семантическая HTML-разметка, skip-link и клавиатурные сценарии.

## Разделы

- `index.html` — главная экспозиция;
- `biography.html` — биография и ключевые переломы;
- `chronology.html` — интерактивная хронология;
- `works.html` — библиотека произведений;
- `ideas.html` — темы и идеи;
- `petersburg.html` — Петербург Достоевского;
- `family.html` — семья и окружение;
- `gallery.html` — визуальный архив;
- `research.html` — литературный и исторический контекст;
- `sources.html` — источники и библиография;
- `404.html` — обработка несуществующих маршрутов;
- `books/` — отдельные досье произведений.

## Локальный запуск

Сборщик и npm-зависимости не нужны.

### Python

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/`.

### Node.js

```bash
npx serve .
```

Для корректной проверки поведения сайта используйте HTTP-сервер, а не `file://`.

## QA

Проверка JavaScript:

```bash
node --check app.js
```

Полная статическая проверка:

```bash
node tests/validate.mjs
```

Валидатор проверяет HTML-документы, `lang`, `charset`, `<title>`, дублирующиеся `id`, `alt` у изображений, локальные `href`/`src`, обязательные страницы и отсутствие удалённых legacy-файлов.

GitHub Actions выполняет те же проверки при push в `main` и в pull request.

## Источники и изображения

Для фактологии используются Литературно-мемориальный музей Ф. М. Достоевского, Русская виртуальная библиотека и Культура.РФ. Визуальные материалы берутся из Wikimedia Commons.

Для каждого внешнего изображения при публичной публикации необходимо отдельно проверить страницу файла Commons и условия его лицензии; `Special:FilePath` сам по себе не является указанием лицензии.

## Доступность

- skip-link к основному содержимому;
- `aria-label` и `aria-expanded` у мобильного меню;
- закрытие меню клавишей Escape;
- закрытие модальных окон Escape и кликом по подложке;
- `prefers-reduced-motion`;
- альтернативный текст у содержательных изображений;
- адаптивная сетка без намеренного горизонтального скролла.

## Ручная проверка перед публикацией

Откройте сайт через локальный HTTP-сервер и проверьте минимум четыре ширины: 360, 768, 1024 и 1440 px. Отдельно пройдите меню, фильтры книг, хронологию, модальные окна, викторину и все ссылки из подвала.
