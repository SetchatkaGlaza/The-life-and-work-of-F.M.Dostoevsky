# Достоевский — цифровая литературная выставка

Полностью статический сайт о Фёдоре Михайловиче Достоевском (1821—1881), пересобранный как небольшая digital exhibition: человек → книги → темы → город → архив → контекст.

## Что внутри

- **Жизнь** — семь биографических переломов вместо длинной простыни.
- **Хронология** — интерактивные ключевые даты.
- **Книги** — 15 отдельных досье произведений.
- **Темы** — свобода, вина, вера, другой человек, унижение, азарт.
- **Петербург** — места биографии и городское пространство прозы.
- **Люди** — семья, друзья, критики и современники.
- **Архив** — портреты, фотографии, рукописи и музейные материалы.
- **Контекст** — литературная и историческая среда.
- **Источники** — музей, библиотеки и визуальные коллекции.

## Запуск

Сборщик и npm-зависимости не нужны.

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/`.

Альтернатива:

```bash
npx serve .
```

## Проверка

```bash
node --check app.js
node tests/validate.mjs
```

GitHub Actions запускает статическую проверку при изменениях в `main`.

## Изображения

Визуальные материалы используют Wikimedia Commons. Для каждого конкретного файла следует проверять страницу файла и его лицензионный статус. Например, рукописный материал Достоевского 1867 года в Commons отмечен как public domain.

Фактологические сведения о Кузнечном переулке, мемориальной квартире и музейной экспозиции сверяются с официальным Литературно-мемориальным музеем Ф. М. Достоевского.

## Принципы

1. Не смешивать факт и интерпретацию.
2. Не превращать реплики персонажей в «мудрости автора».
3. Не делать длинные полотна текста там, где помогает структура.
4. Изображение должно объяснять материал, а не просто заполнять место.
5. Каждая страница должна работать на мобильном экране.
6. `prefers-reduced-motion` учитывается в интерфейсе.
